# SANGRITA

SANGRITA (Searching with Alacrity for New Gamma Ray bursts in Images Taken Already) is the trigger system for [TEQUILA](https://github.com/unam-transients/tequila). The prototype is being developed by [Alan Watson](https://github.com/alanwatsonatwork) in collaboration with Sabina Miranda Quiroga and Liam Watson Palacios.

- Part of [TEQUILA](https://github.com/unam-transients/tequila).
